# เว็บไซต์พอร์ตโฟลิโอ FILM — คู่มือภาษาไทย

🌐 **เว็บไซต์:** https://filmweerayut.github.io/film-portfolio/
📁 **ไฟล์เว็บ (GitHub):** https://github.com/Filmweerayut/film-portfolio
✏️ **หน้าแก้ไข:** https://app.pagescms.org

เว็บนี้เป็นเว็บนิ่ง (static) เปิดฟรีด้วย **GitHub Pages**
ข้อความและรายการผลงานเก็บในไฟล์ `content/works.json` และ `content/site.json` ส่วนรูปผลงานอยู่ในโฟลเดอร์ `uploads/`
แก้ไขผ่านเบราว์เซอร์ได้ด้วย **Pages CMS** (ฟรี ไม่ต้องเขียนโค้ด)

> ⚠️ ตอนนี้ผลงาน 8 ชิ้น ข้อความ About อีเมล และลิงก์โซเชียล เป็น **ข้อมูลตัวอย่าง** — กรุณาแทนที่ด้วยข้อมูลจริง

---

## วิธีแก้ไขเว็บ (Pages CMS)

### เข้าใช้งาน
1. เปิด **https://app.pagescms.org**
2. กด **Sign in with GitHub** → ล็อกอินบัญชี `Filmweerayut`
3. *(ครั้งแรกครั้งเดียว)* ถ้าระบบขอให้ติดตั้ง GitHub App ให้กด **Install** → เลือก **Only select repositories** → เลือก `film-portfolio` → **Install**
4. เลือกรีโป **film-portfolio** (branch `main`)

เมนูด้านซ้ายจะมี **ผลงาน (Works)**, **ข้อความบนเว็บ (Site text)** และ **Media**

### เพิ่มผลงานใหม่
1. กด **ผลงาน (Works)**
2. เลื่อนลงล่างสุด กด **Add an entry / เพิ่ม** (ปุ่ม +)
3. กรอก **ชื่อผลงาน**, เลือก **หมวดหมู่**, ใส่ **ปี**
4. ช่อง **รูปผลงาน** → กดเลือกรูป → **Upload** ไฟล์จากเครื่อง → เลือกรูปที่อัปโหลด
5. ใส่ **คำอธิบาย** (ไม่บังคับ)
6. กด **Save** (มุมขวาบน)
7. รอประมาณ **1 นาที** แล้วรีเฟรชเว็บ ผลงานใหม่จะขึ้น

> ผลงานแสดงตามลำดับในรายการ — อันบนสุดแสดงก่อน ลากเพื่อเรียงลำดับใหม่ได้

### แก้ไข / ลบผลงาน
- กดที่ผลงานเพื่อเปิดแก้ไข
- กดไอคอนถังขยะ / ⋯ → Remove เพื่อลบ
- เสร็จแล้วกด **Save** ทุกครั้ง

### ลบผลงานตัวอย่าง
ลบ "Work 01–08 (ตัวอย่าง)" ทั้ง 8 ชิ้น แล้วเพิ่มผลงานจริง กด Save
(รูปตัวอย่าง `placeholder-0X.svg` ลบได้ที่เมนู **Media**)

### อัปโหลดรูปไว้ก่อน
เมนู **Media** → **Upload** → รูปจะถูกเก็บในโฟลเดอร์ `uploads/` แล้วเลือกใช้ในผลงานได้ภายหลัง

### แก้ข้อความบนเว็บ
เมนู **ข้อความบนเว็บ (Site text)**
- **ส่วนหัว (Hero):** หัวข้อ, ข้อความลายมือ, คีย์เวิร์ดด้านขวา, รูปคาแรกเตอร์
- **เกี่ยวกับ (About):** ข้อความแนะนำตัว, ทักษะ, เครื่องมือ
- **ติดต่อ (Contact):** ใส่อีเมลจริง และลิงก์ Instagram / Behance / Facebook / LINE (ตอนนี้เป็น `#`)
- **ท้ายเว็บ (Footer)**

กด **Save** → รอ ~1 นาที

## เคล็ดลับเรื่องรูป
- ใช้ JPG หรือ WebP กว้างประมาณ 1600px ไฟล์ไม่เกิน ~1–2MB
- การ์ดผลงานเป็นแนวตั้ง 4:5 รูปอัตราส่วนนี้จะสวยที่สุด (รูปอื่นจะถูกครอปตรงกลางในการ์ด แต่กดดูเต็มรูปได้)
- ตั้งชื่อไฟล์ภาษาอังกฤษ ไม่มีเว้นวรรค เช่น `poster-2026.jpg`
- ⚠️ รีโปนี้เป็น **Public** — ทุกไฟล์ที่อัปโหลดคนอื่นเห็นได้ อย่าอัปโหลดไฟล์ส่วนตัว

## เพิ่มหมวดหมู่ใหม่
ปุ่มกรองบนเว็บสร้างจากหมวดหมู่ที่มีผลงานอยู่จริงโดยอัตโนมัติ
ถ้าต้องการชื่อหมวดหมู่อื่น แก้รายการ `values:` ในไฟล์ `.pages.yml` (แก้บน GitHub ได้)

## โครงสร้างไฟล์
| ไฟล์ / โฟลเดอร์ | ใช้ทำอะไร |
|---|---|
| `index.html`, `css/`, `js/` | หน้าเว็บ หน้าตา และการทำงาน |
| `content/works.json` | รายการผลงาน |
| `content/site.json` | ข้อความหน้าแรก / About / Contact / Footer |
| `uploads/` | รูปผลงาน |
| `images/` | รูปคาแรกเตอร์และพื้นหลัง |
| `.pages.yml` | ตั้งค่าหน้าแก้ไขของ Pages CMS (ชื่อฟิลด์ต้องตรงกับไฟล์ JSON) |
| `admin/` | หน้าลิงก์ไปยัง Pages CMS |
| `.nojekyll` | บอก GitHub Pages ให้แสดงไฟล์ตามจริง (ห้ามลบ) |

## แก้ปัญหาที่พบบ่อย
| อาการ | วิธีแก้ |
|---|---|
| Save แล้วเว็บยังไม่เปลี่ยน | รอ 1–2 นาที แล้วรีเฟรชแบบ Ctrl+Shift+R (มือถือ: ปิดแท็บแล้วเปิดใหม่) ดูสถานะได้ที่แท็บ **Actions** ในรีโป |
| ไม่เห็นรีโปใน Pages CMS | ยังไม่ได้ติดตั้ง GitHub App ให้รีโป `film-portfolio` — ดูขั้นตอนที่ 3 ด้านบน |
| เว็บว่าง/ผลงานหาย หลังแก้ | อาจลบฟิลด์สำคัญไป — ไปที่ GitHub → `content/works.json` → History เพื่อย้อนกลับเวอร์ชันก่อน |
| เปิด `index.html` จากเครื่องแล้วไม่มีผลงาน | ต้องเปิดผ่านเว็บจริง หรือรัน `python3 -m http.server` ในโฟลเดอร์ |
